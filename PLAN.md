# 🎨 Landing Page Plan - Deco Decoster

## Project Overview
A rustic & organic themed professional landing page for a house painting business (Deco Decoster) serving both residential and commercial clients. The design emphasizes warmth, craftsmanship, trust, and showcases real transformations through before/after imagery.

---

## Brand Identity
- **Business Name:** Deco Decoster
- **Aesthetic:** Rustic & Organic (warm, natural, trustworthy)
- **Target Audience:** Homeowners + Commercial clients (property managers, real estate)
- **Services:** Interior painting, exterior painting, specialty services (cabinets, decks, staining, trim work)

---

## Design Specifications

### Color Palette
**Primary Colors:**
- Terracotta: `#C25B3B` (accent, buttons)
- Sage Green: `#8BA88E` (secondary elements)
- Warm Gray: `#6B6B6B` (text, borders)

**Accent Colors:**
- Navy Blue: `#2C3E50` (primary CTAs, headers)
- Gold/Amber: `#D4A574` (highlight accents)

**Neutral Colors:**
- Background: `#FDFBF7` (cream/off-white)
- Light Background: `#F5F1ED` (sections)
- Dark Text: `#2D2D2D` (charcoal)
- Light Text: `#666666` (secondary text)

---

### Typography

**Headings:**
- Font Family: `Playfair Display` (serif)
- H1: 48px, bold, navy blue
- H2: 36px, bold, warm gray
- H3: 24px, semi-bold, dark gray

**Body Text:**
- Font Family: `Open Sans` (sans-serif)
- Base: 16px, regular, charcoal
- Small: 14px, regular, secondary gray
- Line Height: 1.6

**Button Text:**
- Font Family: `Open Sans` (sans-serif)
- Weight: 600 (semi-bold)
- Size: 16px
- Letter Spacing: 0.5px

---

### Visual Elements

**Textures & Patterns:**
- Subtle paper/canvas texture overlay on hero section
- Brushed/paint stroke patterns in backgrounds
- Faint geometric patterns in footer

**Shapes & Corners:**
- Button Border Radius: 8px (rounded, organic feel)
- Card Border Radius: 12px
- Image Border Radius: 8px
- Form Input Border Radius: 6px

**Shadows:**
- Card Shadow: `0 4px 6px rgba(0, 0, 0, 0.1)`
- Button Shadow: `0 2px 4px rgba(0, 0, 0, 0.15)`
- Hover Shadow: `0 8px 15px rgba(0, 0, 0, 0.2)`

**Icons:**
- Style: Outline icons with rustic feel
- Library: Feather Icons or Heroicons
- Size: 24px default, 32px for feature icons
- Color: Terracotta or Navy depending on context

## Technical Requirements

### Performance
- Page Load Time: < 3 seconds
- First Contentful Paint: < 1.5 seconds
- Image Optimization: WebP format with lazy loading
- Code Splitting: Route-based chunking
- Minification: CSS, JS production builds

### SEO
- Meta Title: "Deco Decoster | Professional House Painting Services"
- Meta Description: "Transform your space with Deco Decoster's expert interior & exterior painting services. Licensed, insured, and trusted by homeowners and businesses. Get your free quote today!"
- Open Graph tags for social sharing
- Schema.org markup for local business
- Sitemap.xml generation
- Robots.txt configuration

### Accessibility
- WCAG 2.1 AA compliance
- Alt text on all images
- Keyboard navigation support
- ARIA labels on interactive elements
- Color contrast ratios met
- Focus states on all buttons/links

### Responsive Breakpoints
- Mobile: 320px - 640px
- Tablet: 641px - 1024px
- Desktop: 1025px - 1440px
- Large Desktop: 1441px+

## Notes for Development

1. **Mobile-First Approach:** Design for mobile, then enhance for larger screens
2. **Image Optimization:** Critical for gallery-heavy page - use lazy loading, WebP format
3. **Before/After Slider:** This is a key differentiator - make it smooth and intuitive
4. **Trust Signals:** Place license/insurance info in multiple strategic locations
5. **CTA Visibility:** Ensure "Get Quote" button is always accessible (sticky header or floating button on mobile)
6. **Local SEO:** Emphasize service areas throughout for local search optimization
7. **Speed:** Painting customers often research on mobile while at home - optimize for fast loading
